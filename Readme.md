ต้องการ Web app วิเคราะห์ดินสำหรับเกษตรกร โดยมีรายละเอียดดังนี้
ผู้ใช้งานส่วนใหญ่เน้นใช้งานบนมือถือส่วน Admin ใช้คอมปกติ

ส่วนของผู้ใช้งาน
- ผู้ใช้สามารถวิเคราะห์ข้อมูลดินของแปลงตัวเองได้ โดยกรอกข้อมูลดิน เช่น ค่าpH, ความชื้น, ปริมาณปุ๋ย, ปริมาณสารอาหาร, และค่าอื่น ๆ ที่เกี่ยวข้องตามที่ผู้ดูแลกำหนดให้กรอก
- ระบบจะแสดงผลการวิเคราะห์ รวมถึงกราฟของดินเมื่อเทียบกับเส้นเกณฑ์มาตรฐานที่กำหนดโดยผู้ดูแล เช่น ความเหมาะสมของดินต่อพืช, คำแนะนำในการปรับปรุงดิน, แผนการใส่ปุ๋ย, และคำแนะนำในการเพาะปลูก, รวมถึงการแสดงผลลัพธ์ที่คาดหวัง
- ผู้ใช้สามารถบันทึกข้อมูลดินของแปลงตัวเองได้
- ผู้ใช้สามารถดูประวัติการวิเคราะห์ข้อมูลดินของแปลงตัวเองได้

ส่วนของผู้ดูแล
- ผู้ดูแลเป็นผู้กำหนดค่ามาตรฐานต่าง ๆ เช่น ค่า pH, ความชื้น, ปริมาณปุ๋ย, ปริมาณสารอาหาร, และค่าอื่น ๆ ที่เกี่ยวข้องตามที่ผู้ดูแลกำหนดให้กรอก
- ผู้ดูแลเป็นผู้กำหนดเกณฑ์มาตรฐานต่าง ๆ เช่น ความเหมาะสมของดินต่อพืช, แผนการใส่ปุ๋ย, และคำแนะนำในการเพาะปลูก
- ผู้ดูแลเป็นผู้กำหนดพืชที่สามารถเพาะปลูกได้
- ผู้ดูแลเป็นผู้กำหนดปุ๋ยที่สามารถใช้ได้
- ผู้ดูแลเป็นผู้กำหนดสารอาหารที่สามารถใช้ได้
- ผู้ดูแลเป็นผู้กำหนดค่าอื่น ๆ ที่เกี่ยวข้องตามที่ผู้ดูแลกำหนดให้กรอก
- และสามารถเข้าถึงเพื่อดูข้อมูลการวิเคราะห์ของเกษตรกรได้ทุกราย
- แสดง Dashboard รวม
- สามารถเพิ่ม แก้ไข ลบ ผู้ดูแลได้
- ผู้ดูแลเป็นผู้อนุมัติเกษตรกรที่สมัครใหม่

---------------------
แนะนำการใช้ฐานข้อมูลด้วย
เพื่อรองรับการเข้าใช้งานแบบต่อเนื่อง
ผู้ใช้ทุกคนต้องสมัครสมาชิกเพื่อเข้าใช้งาน โดยกรอกข้อมูลดังนี้
1. ชื่อ-นามสกุล
2. อีเมล(ถ้ามี)
3. เบอร์โทรศัพท์
4. รหัสผ่าน
5. ยืนยันรหัสผ่าน
วิธีการเข้าใช้งาน
กรอกเบอร์โทรศัพท์และรหัสผ่านเพื่อเข้าใช้งาน
ผู้ใช้จะมีข้อมูลเป็นแบบส่วนตัว ผู้ใช้งานคนอื่นไม่สามารถเข้าถึงได้
